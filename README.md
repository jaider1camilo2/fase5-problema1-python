# Fase 5 - Problema 1

## Fundamentos de Programación

Solución básica de programación desarrollada para la Fase 5 - Evaluación Final POA del curso Fundamentos de Programación de la Universidad Nacional Abierta y a Distancia (UNAD).

## Descripción

El programa analiza una matriz que contiene información de sesiones de clientes en una plataforma digital. Cada sesión incluye:

- ID del cliente.
- Duración de la sesión en segundos.
- Número de clics.

El programa utiliza una función para clasificar el nivel de compromiso de cada sesión como Alto, Bajo o Medio.

## Reglas de clasificación

- Alto: duración mayor a 180 segundos y más de 8 clics.
- Bajo: duración menor a 60 segundos o menos de 3 clics.
- Medio: cualquier otro caso.
